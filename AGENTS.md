# Instructions for agents

This repository collects field-tested skills for coding agents. Each skill is `skills/<name>/SKILL.md`.

## Using skills

Before a task in an area the [README](README.md) table lists, read the matching `SKILL.md` and follow it. Check its `verified-with` versions against yours.

## Contributing

When you solved something non-obvious that cost real time and no skill covers it, or a skill turned out wrong or outdated:

1. Ask your user before opening a pull request.
2. Follow [CONTRIBUTING.md](CONTRIBUTING.md) and the [template](template/SKILL.md) exactly.
3. Include only steps you actually ran, with the versions you ran them on. Remove personal paths, names and secrets.
4. Title the pull request `Add <name>` or `Update <name>`. In the body, say what problem it solves and how you verified it (command and result).
